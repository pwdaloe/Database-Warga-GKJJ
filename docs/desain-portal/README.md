# Desain Portal Jemaat GKJJ (markup acuan)

Salinan markup dari kanvas desain "Portal Jemaat GKJJ — Desain Beranda" (23 Okt 2026). Berkas `.dc.html` adalah format kanvas desain dan **bukan** kode untuk dipakai langsung; gunakan sebagai acuan tata letak, ukuran, warna, dan teks saat membangun `apps/portal` (lihat `docs/RENCANA_PORTAL_JEMAAT.md`).

| Berkas | Layar |
|---|---|
| `Main.dc.html` | Beranda (HP, 390 px) |
| `Menu.dc.html` | Menu samping (HP) |
| `Pendeta.dc.html` | Temui Pendeta (HP) |
| `Saya.dc.html` | Saya / Masuk (HP). Di rencana, form password diganti penjelasan + tombol ke aplikasi data (keputusan D3) |
| `Desktop.dc.html` | Beranda desktop (fluid) |

Catatan konten: nama pendeta, tanggal, alamat, dan nomor WA adalah **placeholder** (`[...]`); teks ibadah, kegiatan, dan renungan adalah contoh dari mockup awal. Logo adalah penanda sementara.
